# Polos Desktop (Tauri) 开发计划

## 项目概述

将现有 Flutter 婴儿头型测量系统重构为 Tauri + React + TypeScript 版本。

## 现有功能分析（基于 Flutter 代码）

### 核心布局
- 顶部固定 Header（含可折叠侧边导航）
- 三个主页面：Dashboard、婴儿管理（Master-Detail）、系统设置

### Dashboard 首页
- 搜索框（支持手机号/姓名搜索，实时下拉结果）
- 未匹配时直接新建婴儿
- 统计卡片：今日测量、本周测量、总档案数、异常比例
- 今日测量记录表格（分页）

### 婴儿管理模块
- 左侧列表面板（搜索、列表、新建按钮）
- 右侧详情面板：
  - 婴儿基本信息卡片（头像、姓名、性别、月龄/矫正月龄）
  - 信息行（出生日期、孕周、联系电话、建档时间）
  - Tab 切换：测量记录列表 / 发育趋势图
  - 测量记录卡片（含所有指标、分级徽章、操作按钮）
  - 新增记录按钮

### 测量录入（弹窗）
- 婴儿信息展示
- 测量数据表单（头长、头宽、斜径A、斜径B、头围、测量日期）
- 实时计算预览（CR、CVAI、Diff、矫正月龄）
- 分级徽章（颜色区分1-5级）

### PDF 报告
- 生成报告（当前测量 + 历史记录）
- 预览、打印、下载

### 发育趋势图
- CR/CVAI/Diff 趋势折线图
- 头围生长趋势

### 系统设置
- 医院名称配置
- Logo 上传

## 技术决策

| 领域 | 选择 | 说明 |
|------|------|------|
| 状态管理 | Zustand | 轻量、简单、React 友好 |
| 数据获取 | TanStack Query | 异步状态管理、缓存 |
| 图表 | Recharts | React 集成好、灵活 |
| PDF | @react-pdf/renderer | React 风格、支持中文 |
| 表单 | React Hook Form | 高性能、验证支持 |
| 日期 | date-fns | 轻量、Tree-shaking |
